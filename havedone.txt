STEP 8 — ML Monitoring / Drift Detection (Layer 6)
--------------------------------------------------------------------------------
File created:
   - src/monitoring.py
     * Loads reference dataset (training distribution baseline).
     * Loads recent predictions from predictions_log.csv (configurable window,
       default 30 days).
     * Numeric drift: PSI (Population Stability Index) per feature.
         - PSI < 0.10 → No change (low)
         - PSI 0.10–0.20 → Moderate change (medium)
         - PSI > 0.20 → Significant drift (high) ← triggers alert
     * Categorical drift: chi-square normalized score per feature.
         - Score > 0.15 → drift detected
     * Drift summary: share of drifted features vs threshold (default 30%).
     * Prediction drift: checks if fraud_rate is between 0.1% and 20%.
     * Saves JSON reports → data/monitoring_reports/data_drift_<ts>.json
                         → data/monitoring_reports/prediction_drift_<ts>.json
     * ALERT: if dataset_drift=True OR prediction out-of-range:
         - Writes data/alerts/alert_<timestamp>.json
         - Logs WARNING with drift share and recommended action (retrain).
     * CLI flag: --window-days N
